# Babot — 三支链 Stewart 平台球体平衡控制系统

基于 Arduino 的球体平衡控制固件：16 路红外阵列感知球位，PID 闭环计算平台倾角，三支链逆运动学解算舵机角，驱动 Stewart 平台实时回中。

## 硬件

| 部件 | 说明 |
|---|---|
| 主控 | Arduino（Uno / Nano 兼容，需 A0 模拟输入 + 3 路 PWM） |
| 传感器 | 16 路红外接收管，4×4 阵列，发射端共用 1 路控制 |
| 模拟复用 | CD74HC4067（16 通道） |
| 执行器 | 3 路舵机（金属齿，如 MG996R） |
| 数字电位器 | 8 位 SPI 型，用于调节红外发射强度 |

### 引脚定义

| 功能 | 引脚 |
|---|---|
| 红外接收 | A0 |
| 按键 | A1 |
| 红外发射 LED | 7 |
| 状态 LED | 8 |
| 舵机 A / B / C | 11 / 10 / 9 |
| 复用器 S0 / S1 / S2 / S3 | 5 / 13 / 6 / 12 |
| 数字电位器 CS / DIN / SCLK | 4 / 1 / 0 |

## 编译与烧录

Arduino IDE 直接打开 `Stewart-code.ino`（文件名需与文件夹同名），选择对应板卡与端口后上传。串口监视器波特率设为 **115200**。

## 操作方式

单个按键完成全部操作，按击次数与时长区分：

| 手势 | 动作 |
|---|---|
| 单击 | ON ⇄ OFF 切换（平衡 / 水平） |
| 三击 | 进入 CALIBRATION（校准） |
| 四击 | 进入 ASSEMBLY（舵机扫描，用于装配检查） |
| 长按（≥1 s） | 校准流程中切换舵机 A → B → C → 完成 |

### 四种模式

- **ON** — 闭环平衡。检测到球后启动 PID，输出经 EMA 平滑后驱动平台。
- **OFF** — 平台锁定水平，不参与控制。
- **ASSEMBLY** — 三个舵机依次 100° → 180° → 100° 扫描，用于装配与行程检查。
- **CALIBRATION** — 单击递增当前舵机偏置，长按切换到下一路；全部完成后偏置写入 EEPROM 并自动回到 ON。

## 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `P_GAIN` / `I_GAIN` / `D_GAIN` | 3.0 / 0.04 / 25.0 | PID 增益 |
| `IR_SMOOTH_ALPHA` | 0.7 | 传感器 EMA 系数 |
| `OUTPUT_SMOOTH_ALPHA` | 0.9 | 输出 EMA 系数 |
| `BALL_THRESHOLD` | 350 | 球在位判定阈值（max−min） |
| `VEL_SCALE` | 0.001 | 微分项自适应缩放系数 |
| `PLATE_HEIGHT` | 65 | 平台中位高度 |
| `R1` / `R2` | 50 / 39.2 | 舵机臂长 / 连杆长 |
| `BASE_R` / `PLAT_R` | 32.9/√3 / 107.9/√3 | 下 / 上平台铰链分布半径 |

PID 串口在线调参与数据上报默认关闭（`ENABLE_SERIAL_STREAM 0`，保持原有行为）。将其改为 `1` 后，每 3 帧输出一次完整帧，并支持向串口发送 `P3.5I0.05D28` 形式的指令在线调整增益，无需重新烧录。

## 实现要点

**感知**：每轮采样先熄灭红外 LED 读取 16 路环境光，再点亮读取反射值，两轮相减消除环境光干扰；差分值经 EMA（α=0.7）平滑后进入质心计算。

**质心估计**：4×4 阵列归一化后取三次方加权，形成尖峰响应，使球正下方少数传感器主导估计；计算时向四周扩展为 6×6 镜像网格（`mirrorIdx`），补偿球靠近边缘时质心向中心偏移的系统误差。

**控制**：双轴独立 PID，微分项乘以自适应系数 `|v|/(|v|+VEL_SCALE)`，低速时衰减微分以抑制噪声；输出再经 EMA（α=0.9）平滑后送入逆解。丢球时保留 1 s 内最后输出，重新上台时跳帧 2 个周期等待读数稳定。

**逆运动学**：三支链按 0° / 120° / 240° 均布。先由 roll、pitch 构造旋转矩阵求上平台铰点坐标，再用余弦定理由支链长度反解舵机角。

**时序**：主循环分两档——快路径每轮处理按键与 LED，30 Hz 路径（`micros()` 计时）执行采样、PID 与逆解，避免阻塞输入响应。

详细设计与公式推导见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 配套工具：实时监控台

`viz/` 提供一个基于 Streamlit 的实时可视化工具：热力图展示 16 路传感器强度与球位分布，动态曲线跟踪球位与平台姿态，支持时间窗口与位置筛选，并对断流、越界、无球等异常给出提示。

```bash
cd viz
pip install -r requirements.txt
streamlit run app.py
```

默认使用内置模拟数据，无需硬件即可预览界面；串口模式需先取消 `loop()` 中 `sendSerialData()` 或 `sendGraphData()` 的注释。详见 [viz/README.md](viz/README.md)。

## 已知限制

- 无单元测试，验证依赖实机调试与串口数据观察。
- 增益为实机试凑值，更换平台几何或舵机需重新标定。
- 仅实现 roll / pitch 双轴平衡，未做 height 动态调节。
