# 系统架构与实现说明

本文描述固件的实际实现，所有参数与行为均以 `Stewart-code.ino` 为准。

## 1. 系统概述

三支链 Stewart 平台上的球体平衡控制系统。16 路红外传感器阵列检测球位，双轴 PID 计算平台倾角，三支链逆运动学解算舵机角度，构成「感知 → 控制 → 执行」闭环，控制频率 30 Hz。

平台仅由 3 个舵机驱动，可实现 roll、pitch 两轴姿态调节（height 固定），属于 Stewart 平台的简化构型，而非六自由度全并联机构。

```
16 路红外 ──► 差分采样 ──► EMA 平滑 ──► 立方加权质心 ──► 球位 (x, y)
                                                            │
                              ┌─────────────────────────────┘
                              ▼
                       双轴 PID ──► 输出 EMA ──► 逆运动学 ──► 3 路 PWM ──► 舵机
```

## 2. 硬件与接线

| 部件 | 型号 / 规格 |
|---|---|
| 主控 | Arduino（Uno / Nano 兼容） |
| 传感器 | 16 路红外接收管，4×4 阵列，发射端共用 1 路 GPIO 控制 |
| 模拟复用 | CD74HC4067（16 通道） |
| 执行器 | 3 路舵机，金属齿 |
| 红外强度调节 | 8 位数字电位器（SPI 位操作） |

| 功能 | 引脚 | 说明 |
|---|---|---|
| 红外接收 | A0 | 复用器公共端输入 |
| 按键 | A1 | 单键，内部上拉逻辑按高电平按下处理 |
| 红外发射 LED | 7 | 采样时交替亮灭 |
| 状态 LED | 8 | 模式指示 |
| 舵机 A / B / C | 11 / 10 / 9 | `Servo::attach` 直驱，无外部驱动板 |
| 复用器 S0 / S1 / S2 / S3 | 5 / 13 / 6 / 12 | 通道选择 |
| 数字电位器 CS / DIN / SCLK | 4 / 1 / 0 | 软件 SPI |

**通道映射**：复用器通道 `i` 对应阵列第 `i / 4` 行、第 `i % 4` 列（行优先）。物理接线须与此顺序一致，否则质心方向会错位。

## 3. 感知链路

### 3.1 差分采样

红外接收管同时受环境光与自身反射影响，采用「灭灯 / 亮灯两轮采样」分离二者。16 路接收端经 CD74HC4067 复用后接入 A0，发射端由单路 GPIO 统一开关：

```
IR_LED = LOW   → 逐通道读取 16 路环境光  ambient[i]
IR_LED = HIGH  → 逐通道读取 16 路反射光  irLight[i]
diff[i] = irLight[i] - ambient[i]
```

每通道切换后等待 600 μs 让复用器与 ADC 稳定。单轮完整采样耗时约 19.2 ms（16 × 2 × 600 μs），占 33 ms 控制周期的 58%，是当前时序的主要开销。

ADC 预分频改为 32（`ADCSRA` 低三位写 `0b101`），转换时钟 500 kHz，单次转换约 26 μs。

### 3.2 EMA 平滑

```
irSignal[i] += α · (diff[i] - irSignal[i])      α = 0.7
```

一阶低通，30 Hz 采样下等效截止频率约 5.7 Hz（`fc = -fs·ln(1-α)/2π`），抑制 ADC 量化噪声与光照抖动。

### 3.3 球位判定

```
max(irSignal) - min(irSignal) ≥ 350   → 判定球在台
```

用极差而非绝对阈值，可自适应红外发射强度漂移。

### 3.4 立方加权质心

1. 归一化：`v[i] = (irSignal[i] - min) / (max - min)`
2. 三次方加权：`w[i] = v[i]³`，形成尖峰响应，使球正下方 2–3 个传感器主导估计
3. 边缘镜像扩展：把 4×4 网格向外扩为 6×6，越界索引按 `{0,0,1,2,3,3}` 镜像回边界，补偿球靠近边缘时质心向中心偏移的系统误差
4. 加权平均后减去 1.5，得到以平台中心为原点的格点坐标，范围 −1.5 … +1.5

格点坐标乘以传感器间距即得物理坐标。间距由阵列实际布局决定，当前可视化层按 30 mm 换算。

## 4. 控制链路

### 4.1 双轴 PID

X、Y 两轴独立计算，结构相同：

```
error   = 0 - position
integ  += I_GAIN · error
vel     = error - lastError
scale   = |vel| / (|vel| + VEL_SCALE)        VEL_SCALE = 0.001
output  = P_GAIN · error + integ + D_GAIN · scale · vel
```

**微分项自适应**：`scale` 在速度趋近 0 时趋于 0，速度增大时趋于 1。低速段抑制微分噪声放大，高速段保留完整阻尼。这是本实现与教科书 PID 的主要差异。

积分项无显式抗饱和逻辑，仅在球离开平台时整体清零。

### 4.2 输出平滑

```
smooth = 0.9 · output + 0.1 · smooth_prev
```

α = 0.9 的 EMA，抑制舵机高频抖动，代价是引入约 1–2 帧相位滞后。

### 4.3 角度限幅

限幅发生在舵机写入前：

```
a = constrain(a, -10, 85)
servo.write(offset - a)
```

`offset` 默认 100，校准后可能偏移 ±25，因此实际舵机角度约在 15°–110° 之间。

### 4.4 球上台与离台处理

| 事件 | 处理 |
|---|---|
| 检测到球上台 | `skipCounter = 2`，跳过 2 个控制周期等待读数稳定；重置误差基准 |
| 球暂时丢失 | 1 s 内保持最后一次输出，避免舵机突变 |
| 球持续离台 | 清零积分与误差、平台回水平 |

## 5. 逆运动学

### 5.1 几何

三支链在 120° 均布，铰点角度 `a ∈ {0°, 120°, 240°}`。上平台铰点局部坐标 `(PLAT_R·cos a, PLAT_R·sin a, height)`，下平台铰点 `(BASE_R·cos a, BASE_R·sin a)`。

### 5.2 姿态变换

先绕 X 轴 pitch，再绕 Y 轴 roll：

```
x1 =  px·cos(pitch) + pz·sin(pitch)
z1 = -px·sin(pitch) + pz·cos(pitch)
y1 =  py·cos(roll)  - z1·sin(roll)
z2 =  py·sin(roll)  + z1·cos(roll)
```

### 5.3 支链长度与舵机角

```
d      = |(x1, y1, z2) - (BASE_R·cos a, BASE_R·sin a, 0)|
cosθ   = (R1² + d² - R2²) / (2·R1·d)
angle  = atan2(dz, dx_local) - acos(cosθ)
```

其中 `R1` 为舵机臂长、`R2` 为连杆长，`dx_local = dx·cos a + dy·sin a` 把支链投影到该支链所在径向平面。

三路角度按 `A←angle[2]`、`B←angle[0]`、`C←angle[1]` 映射到舵机，与物理装配顺序对应。

## 6. 模式与交互

单键操作，靠按击次数与时长区分：

| 手势 | 触发条件 | 动作 |
|---|---|---|
| 单击 | 500 ms 内无后续按击 | ON ⇄ OFF |
| 双击 | 500 ms 内两击 | 保留未使用 |
| 三击 | 500 ms 内三击 | 进入 CALIBRATION |
| 四击 | 500 ms 内四击 | 进入 ASSEMBLY |
| 长按 | 持续 ≥ 1000 ms | 校准流程中切换舵机 |

| 模式 | 行为 | LED |
|---|---|---|
| ON | 闭环平衡 | 300 ms 闪烁 |
| OFF | 平台锁定水平 | 常灭 |
| ASSEMBLY | 三舵机依次 100° → 180° → 100°，每步 250 ms | 双闪 |
| CALIBRATION | 逐路调节舵机偏置 | 50 ms 快闪 |

## 7. 校准与持久化

进入 CALIBRATION 时三路偏置重置为 100，平台降到 70° 便于观察。

- 单击：当前舵机偏置 +1
- 长按：切到下一路（A → B → C → 完成）
- 完成：三路偏置各减 25 后写入 EEPROM（地址 0 / 4 / 8），回到 ON

减 25 是因为校准观察位（25°）与工作位（0°）之间存在固定偏置差，属于装配经验值。上电时从 EEPROM 读取并约束在 50–150。

## 9. 时序

主循环分两档执行：

| 路径 | 频率 | 内容 |
|---|---|---|
| 快路径 | 每轮 loop | 按键扫描、模式切换、LED 闪烁 |
| 控制路径 | 30 Hz（`micros()` 判 33333 μs） | 采样、质心、PID、逆解、舵机写入 |

按钮状态用「锁存」方式跨两档传递（`lastPress`），避免快速按击落在 30 Hz 间隙被丢弃。

单周期预算 33.3 ms 内：采样约 19.2 ms，质心、PID 与逆解（含三角函数）为毫秒级，余量约 10 ms 以上。

## 10. 调试接口

串口 115200，默认不输出数据（`ENABLE_SERIAL_STREAM 0`）。将宏改为 1 后：

- 每 3 帧输出一次完整帧（10 Hz）：`ir0..ir15, cx, cy, sx, sy`
- 接受 `P3.5I0.05D28` 形式的指令在线改增益，无需重新烧录

分频是为了避免 20 个浮点数占满带宽（30 Hz 下约 140 B/帧，12 ms 发送时间会挤占控制周期）。

配套的实时可视化工具见 [`viz/`](../viz/README.md)。

## 11. 已知限制

- **自由度**：3 支链只能控制 roll / pitch，height 固定，无法实现六自由度位姿。
- **无自动化测试**：验证依赖实机调试与串口数据观察，无单元测试与 CI。
- **增益为试凑值**：更换平台几何、舵机型号或球体质量后需重新整定。
- **采样开销偏高**：单轮采样 19.2 ms 占周期 58%，若提高控制频率需改用并行采样或更快传感器。
- **校准偏移为经验值**：完成时的 −25 偏移基于当前装配，结构变更后需重新确认。
