# Stewart 平台实时监控台

针对 Babot / Stewart 平衡球项目的 Python 可视化工具：实时读取平台数据，用热力图呈现传感器强度与球位分布，用动态曲线跟踪位置与姿态趋势。

## 功能

| 模块 | 说明 |
|---|---|
| 传感器热力图 | 4×4 红外阵列当前帧强度，叠加球位、目标点与筛选区域 |
| 位置分布密度 | 时间窗口内球位二维直方图，看球在哪些区域停留最多 |
| 动态曲线 | 球 X/Y 位置与平台 roll/pitch 随时间变化，支持按指标开关 |
| 时间筛选 | 最近 10 / 20 / 30 / 60 / 120 / 300 秒 |
| 位置筛选 | 全部区域 / 中心区 / 边缘区 / 自定义半径 |
| 异常提示 | 断流、越界、无球、NaN、解析失败率过高均给出明确告警 |
| 刷新控制 | 自动刷新（0.3–2s 可调）+ 手动刷新 + 清空缓冲 |

## 快速开始

```bash
cd viz
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 http://localhost:8501。默认使用**模拟数据**，无需连接硬件即可看到完整效果。

## 三种数据源

### 1. 模拟数据（默认）

内置闭环物理仿真：PID 由球位误差计算平台倾角，倾角驱动球加速，叠加持续微扰与偶发推球。用于界面验证与演示。

### 2. 串口设备

固件默认不输出数据，需把 `ENABLE_SERIAL_STREAM` 由 `0` 改为 `1` 后重新烧录，再选择下列任一输出：

```cpp
// 方案 A：完整帧（16 路强度 + 球位 + 目标）
sendSerialData();

// 方案 B：仅姿态与位置
sendGraphData();
```

开启后固件每 3 帧（10 Hz）输出一次完整帧。

`sendSerialData()` 输出 20 个逗号分隔值：

```
ir0,ir1,...,ir15,cx,cy,sx,sy
```

其中 `cx/cy/sx/sy` 为格点单位，工具会乘以 30mm 转为平台坐标（mm）。

`sendGraphData()` 输出键值对，工具自动识别：

```
smoothRoll:0.12,smoothPitch:-0.30,PlateRoll:0.15,PlatePitch:-0.28,MeasX:0.03,MeasY:-0.11
```

### 3. CSV 回放

上传包含以下列的 CSV，按时间戳节奏循环回放：

| 列 | 必需 | 说明 |
|---|---|---|
| `t` | 是 | 相对时间（秒） |
| `x`, `y` | 是 | 球位置（mm） |
| `roll`, `pitch` | 否 | 平台姿态（°） |
| `ir0` … `ir15` | 否 | 16 路强度 |

## 异常提示对照

| 提示 | 触发条件 | 建议处理 |
|---|---|---|
| 数据已中断 Ns | 最后一条数据超过 2 秒 | 检查串口连接、波特率、固件是否在输出 |
| 未检测到球 | 当前帧 max−min 低于阈值 350 | 确认球在平台上、红外发射强度合适 |
| 球位置超出检测区 | 距中心 > 45mm | 坐标不可信，等待球回到台面 |
| 传感器数据含 NaN/Inf | 解析出非法数值 | 检查串口帧格式与校验 |
| 解析失败率 X% | 无效行占比 > 20% | 输出格式与固件不一致，核对解析分支 |
| 数据源初始化失败 | 串口被占用或 CSV 不存在 | 关闭占用程序、确认文件路径 |

## 说明

- 模拟源用于界面与交互验证，其物理模型做了简化，不作为控制器性能评估依据。
- 位置坐标统一为平台坐标系，单位 mm，原点在平台中心；检测区半宽 45mm（4×4 阵列 @ 30mm 间距）。
